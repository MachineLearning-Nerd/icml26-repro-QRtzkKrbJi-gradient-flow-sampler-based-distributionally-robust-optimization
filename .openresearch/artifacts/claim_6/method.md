# Claim 6 method

Three deliberately different checks are cumulative.

1. `certificate.py` asks SymPy to reduce the conditional integrand identity
   to exact zero with positive symbolic parameters. It also records the
   marginal-elimination and entropy-disintegration steps and their required
   normalization facts.
2. `independent_checker.py` independently uses adaptive SciPy quadrature on
   `Y=R`. It uses a coercive quartic potential, four distinct conditioning
   locations, unrelated Gaussian proposal densities, and bounded feasible
   perturbations of the normalized Gibbs density. It checks normalization,
   the variational identity, Euler-Lagrange stationarity, and nonnegative
   objective gaps.
3. `negative_control.py` replaces `a` by `2a` only in the Gibbs exponent. It
   must exit 1 because the claimed stationary functional derivative then
   varies with `y`.

`verifier.py` runs all three in separate processes. It requires the certificate
and independent checker to exit zero, requires the control to exit one for its
named reason, checks the recorded raw JSON, and exits nonzero on any mismatch.

The raw reference values were generated by `generate_raw.py`, a separate
standard-library composite-Simpson implementation. The adaptive-quadrature
checker does not import or call that generator.

Fixed cumulative command:

`uv run --frozen --no-dev python -m reproduction.run_all`

Determinism: there is no randomness in this claim check. Numerical grids,
quadrature tolerances, conditioning points, and perturbations are fixed in
source.
